📌 About The Project

AI-ReconX is a Python-based reconnaissance and OSINT automation tool developed for cybersecurity learners, ethical hackers, and security researchers.

The main objective of this project is to simplify and automate reconnaissance activities by integrating multiple information-gathering and security analysis modules into a single framework.

AI-ReconX provides a centralized platform for performing domain analysis, DNS enumeration, subdomain discovery, IP lookup, security header analysis, SSL inspection, and automated report generation.

---

✨ Key Features

AI-ReconX includes multiple reconnaissance and security analysis modules.

Module| Description
Domain Information| Collects domain-related information
Subdomain Enumeration| Discovers subdomains
DNS Enumeration| Retrieves DNS records
IP Lookup| Collects IP-related information
WHOIS Lookup| Retrieves domain registration information
SSL Information| Analyzes SSL certificate information
Security Headers| Checks HTTP security headers
Directory & File Discovery| Discovers accessible directories and files
AI Analysis| Provides AI-assisted security analysis
Report Generation| Generates reconnaissance reports

⚙️ Installation Guide

Step 1: Clone Repository

git clone https://github.com/hackwithnarendra-hue/AI-ReconX.git

Step 2: Navigate to Project Directory

cd AI-ReconX

Step 3: Create Virtual Environment

python -m venv venv

Step 4: Activate Virtual Environment

source venv/bin/activate

Step 5: Install Dependencies

pip install -r requirements.txt

Step 6: Run AI-ReconX

python reconx.py
